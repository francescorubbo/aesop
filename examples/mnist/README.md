# MNIST Architecture Search Example

This example demonstrates using **Aesop** to autonomously search for better neural network architectures on the MNIST digit classification task.

## Overview

The example includes:
- A baseline PyTorch model (`BaselineModel`) with editable architecture/hyperparameters
- A training script that evaluates accuracy and writes results to `eval_result.json`
- A validation script (`aesop_validate.sh`) for static checks and training execution
- Automatic experiment tracking and Git-based versioning

## Prerequisites

1. **Install Aesop CLI** (from the repository root):
   ```bash
   npm install
   npm run build
   ```

2. **Set up environment** (from the repository root):
   ```bash
   # Install dependencies
   cd examples/mnist
   uv sync

   # Or use the setup script
   ./setup.sh
   ```

3. **Configure API key** for the embedded agent:
   ```bash
   export ANTHROPIC_API_KEY=sk-...  # For Claude
   # or
   export OPENAI_API_KEY=sk-...     # For OpenAI
   ```

## Quick Start: Manual Training

First, let's verify the setup works with manual training:

```bash
cd examples/mnist

# Run the training script directly
uv run python train.py

# Check the results
cat eval_result.json
```

You should see output like:
```json
{
    "accuracy": 0.8912,
    "epochs": 1
}
```

## Running an Architecture Search with Aesop

Aesop can autonomously improve the model by modifying the architecture and hyperparameters in `train.py`.

### Step 1: Start an Interactive Session

```bash
aesop interactive
```

### Step 2: Run an Automated Experiment

Within the interactive session, ask the agent to improve the model:

```
Improve the model to achieve >95% accuracy on MNIST. Focus on:
- Increasing model capacity (more layers, wider layers)
- Tuning hyperparameters (learning rate, batch size)
- Trying different activation functions
```

The agent will:
1. Edit `train.py` to modify the model architecture
2. Run `aesop_validate.sh` to check and train
3. Review results and iterate if needed

### Step 3: Non-Interactive Mode

You can also run experiments directly from the command line:

```bash
# Run a single experiment prompt
aesop run "Improve the baseline model to achieve >95% accuracy by adding more layers"

# Or use the experiment branch workflow
aesop branch "Test deeper network architecture"
aesop dispatch
aesop status
```

## Experiment Workflow

### 1. Create a Hypothesis Branch

```bash
aesop branch "Explore convolutional architecture"
```

### 2. Make Modifications

The agent will modify `train.py`:
- **Architecture changes**: Add layers, change activation functions, add dropout
- **Hyperparameter tuning**: Adjust learning rate, batch size, epochs
- **Regularization**: Add dropout, batch normalization

### 3. Validate and Execute

```bash
# Manual validation
./aesop_validate.sh

# Or dispatch through Aesop
aesop dispatch
```

### 4. Track Results

Results are logged to `experiments.jsonl`:
```jsonl
{"timestamp":"...","branch":"hypothesis/explore-conv","commitHash":"abc123","status":"success","metrics":{"accuracy":0.9621,"epochs":5}}
```

### 5. Merge Successful Experiments

```bash
aesop merge hypothesis/explore-conv main
```

## Configuration

### Customizing the Experiment

Modify the editable sections in `train.py`:

```python
# ======================================================================
# AESOP SANDBOX
# The agent should focus its mutations on this architecture and the hyperparameters.
# ======================================================================
class BaselineModel(nn.Module):
    def __init__(self) -> None:
        super().__init__()
        # Agent can modify: layer sizes, add layers, change activations
        ...

LEARNING_RATE: float = 0.01  # Agent can tune this
EPOCHS: int = 1               # Agent can increase this
BATCH_SIZE: int = 64           # Agent can tune this
# ======================================================================
```

### Adjusting Validation Thresholds

Modify `aesop_validate.sh` to change what constitutes a successful experiment:

```bash
# Add custom accuracy threshold check
python -c "
import json
with open('eval_result.json') as f:
    result = json.load(f)
    assert result['accuracy'] > 0.95, f'Accuracy {result[\"accuracy\"]} too low'
"
```

## Troubleshooting

### CUDA not available
The script automatically falls back to CPU:
```bash
# Force CPU even if CUDA available
CUDA_VISIBLE_DEVICES="" uv run python train.py
```

### Ruff/Type checking errors
Make sure dependencies are installed:
```bash
uv sync
uvx ruff check train.py  # Test linting
uvx ty check train.py   # Test type checking
```

### Experiment branch issues
```bash
# Check current branch status
git status

# List all experiment branches
git branch -a | grep hypothesis

# Reset to main if needed
git checkout main
```

```python
result_payload = {
```
